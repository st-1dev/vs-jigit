# JiGit для VS Code

Единый экран Git для workspace с несколькими репозиториями.

## Установка и запуск

Установите `vs-jigit-*.vsix` через **Extensions → … → Install from VSIX…**.
Требуется VS Code 1.95+, установленный Git с поддержкой `git switch` и
включённое встроенное расширение Git.

Работает в доверенном workspace, в том числе через Remote SSH / Dev Containers,
если Git доступен на удалённой стороне.

Откройте **JiGit: Open Changes** из палитры команд или нажмите `Ctrl+Alt+G`
(`⌘+Alt+G` на macOS). Значок JiGit в Activity Bar открывает список
репозиториев; кнопка также доступна в заголовке Source Control.

Расширение использует список репозиториев встроенного Git-плагина: поддерживает
несколько корневых папок, обнаруженные вложенные репозитории и worktree. Если
репозиторий отсутствует, сначала откройте его во встроенном Source Control. Для
настройки обнаружения используются штатные параметры
`git.autoRepositoryDetection` и `git.repositoryScanMaxDepth`.
